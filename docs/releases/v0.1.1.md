# Desk OCR v0.1.1

This patch fixes the packaged Windows application reporting that image processing was available only in an Electron desktop window.

## Fixed

- The sandbox-compatible preload bridge is now built as CommonJS and loads correctly from the packaged application.
- The Windows smoke test now verifies `window.deskOCR` in the packaged renderer in addition to exercising the bundled OCR service with a real image.

## Windows preview notes

- The installer remains unsigned, so Windows SmartScreen may display an unknown-publisher warning.
- Only Windows x64 has been packaged and smoke-tested.
- OCR models are downloaded on the first recognition request and cached locally.
- Verify the installer against `SHA256SUMS.txt` before running it.
