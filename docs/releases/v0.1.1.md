# Desk OCR v0.1.1

This patch fixes the packaged preload bridge and adds the first macOS arm64 preview. Desk OCR continues to run OCR locally and bundles its private Python/PaddleOCR runtime on both release platforms.

## Added

- DMG and ZIP artifacts for Apple Silicon Macs.
- A bundled Python 3.12, PaddleOCR, and PaddlePaddle runtime for macOS arm64.
- macOS screen-recording permission metadata and guidance for denied access.

## Fixed

- The sandbox-compatible preload bridge is now built as CommonJS and loads correctly from the packaged application.
- The Windows smoke test now verifies `window.deskOCR` in the packaged renderer in addition to exercising the bundled OCR service with a real image.

## Windows preview notes

- The installer remains unsigned, so Windows SmartScreen may display an unknown-publisher warning.
- Windows x64 remains supported by the existing NSIS packaging workflow.
- OCR models are downloaded on the first recognition request and cached locally.

## macOS preview notes

- The DMG and ZIP support Apple Silicon Macs; Intel Macs are not included in this preview.
- The build is unsigned and not notarized, so use Control-click → Open for the first launch.
- Screen capture requires permission in System Settings → Privacy & Security → Screen & System Audio Recording.
- OCR models are downloaded on the first recognition request and cached locally.
