# Desk OCR v0.1.2

This preview adds application settings and a complete English interface while keeping Chinese as the first-run default. Changing the interface language does not replace or modify the current screenshot, OCR results, search query, or selected match.

## Added

- A Settings dialog with a Chinese-default interface and an English option.
- Local persistence for the selected interface language only.
- English controls, status messages, OCR errors, native image dialogs, and macOS screen-permission guidance.
- Automated macOS arm64 DMG and ZIP builds alongside the Windows x64 installer.

## Privacy

- Screenshots, recognized text, and search queries remain in memory and are not persisted by Desk OCR.
- The interface language is the only UI preference saved locally.
- Switching languages does not rerun OCR or change the screenshot and recognized content already displayed.

## Preview notes

- Windows x64 and Apple Silicon macOS builds are unsigned.
- Windows may show a SmartScreen warning for an unknown publisher.
- macOS may require Control-click → Open on first launch and screen-recording permission for capture.
- OCR models are downloaded on the first recognition request and then reused from the application model cache.
- Intel Macs and Linux installers are not included in this preview.
