# Desk OCR v0.1.0

Desk OCR v0.1.0 is the first installable Windows x64 preview. It captures the current display or opens a local image, performs OCR on the device, and lets you search, select, and copy recognized text.

## Windows preview

- The installer bundles the private Python, PaddleOCR, and PaddlePaddle runtime. End users do not need Node.js or Python.
- OCR models are downloaded on the first recognition request and reused from the application model cache.
- Screenshots and OCR results remain local; the app contains no telemetry or hosted inference.
- Verify the installer against `SHA256SUMS.txt` before running it.

## Known limitations

- This preview is unsigned, so Windows SmartScreen may display an unknown-publisher warning.
- Only Windows x64 has been packaged and smoke-tested. macOS and Linux remain source-development targets and are not release-tested.
- The bundled local OCR runtime makes the installer large.
- Automatic updates are not implemented.
