# Desk OCR v0.1.3

This preview adds drag-to-select region capture. Start a capture from the application or with `Command/Ctrl + Shift + O`, then drag over the part of the display that should be recognized. The captured region and OCR processing remain local.

## Added

- A full-display selection overlay for choosing the exact region to recognize.
- `Esc` and right-click cancellation without replacing the current screenshot or OCR result.
- High-DPI coordinate scaling so the selected area maps to the original-resolution capture on Retina and scaled displays.
- Chinese and English selection guidance; interface language changes do not alter screenshots or OCR content.
- A README demo animation and localized application showcase images.

## Security and privacy

- Region-selection actions use explicit preload methods, and the main process accepts them only from the active selection window.
- Electron renderer sandboxing, context isolation, disabled Node.js integration, and denied external navigation remain enabled.
- Full-display capture is held only in memory long enough to crop the selected region; Desk OCR does not persist or upload it.

## Preview notes

- Windows x64 and Apple Silicon macOS builds are unsigned.
- Windows may show a SmartScreen warning for an unknown publisher.
- macOS may require Control-click → Open on first launch and screen-recording permission for capture.
- OCR models are downloaded on the first recognition request and then reused from the application model cache.
- Intel Macs and Linux installers are not included in this preview.
